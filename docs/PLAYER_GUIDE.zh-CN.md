# Bloodborne 本机游玩指南

启动入口为 `/home/arinp/bloodborne/launch.sh`。它打开完整启动器，使用安装目录的设置、
游戏和现有存档；开发工作树不是正式入口。需要 Steam/Lutris 时仍使用这个入口。

版本、功能清单与未解决问题见[项目现状](PROJECT_STATUS.zh-CN.md)，发展方向见[路线图](NRBRIDGE_ROADMAP.zh-CN.md)。

## 开始与退出

1. 确认游戏和存档目录正确。已有本机安装无需重新配置模型或运行环境。
2. 在画面页选择分辨率、超分档位、NR 和帧生成。可从 1080p Quality 开始；内存模型默认 New，需要对照时可切 Old。
3. 进入能操作角色的场景后按 F8 开启 NR。后续 F8 切换 NR 效果；FG 独立控制。
4. 正常关闭游戏，等待退出和存档同步完成，再关闭启动器。

NR 画质策略默认 Legacy。NR 预设可选 B、A 或模型默认；NR 画质分辨率与屏幕输出分别设置，
提高前者会增加显存和计算开销。1440p DLAA 与高 NR 执行分辨率的组合更耗显存。

## 超分、NR 与帧生成

- 超分可选 DLSS、FSR 等已有实现；DLAA 保留输出分辨率进行重建。
- NR 可独立关闭；关闭超分而保持 NR 开启为 NR-only，也能配合帧生成。
- AMD FSR 为 x2；快速转镜时生成图可能有植被错位。关闭 NR 不能消除此 FSR 缺陷。
- NVIDIA DLSS 支持 2X–6X。高倍率增加生成工作和显存，未必改善真实游戏帧率或响应。
- Smooth Motion 暂不可用，安全退出尚未完成验收，不会静默改用其他算法。
- 多分辨率、SR 档位、16:10/超宽屏与 Old/New 已有支持；不是所有组合都经过逐项画质验收。

当前 FG 开关和 DLSS GPU 模式的倍率可在游戏内调整。不同 FG 算法使用各自运行时，
切换算法需要正常退出并重新启动；菜单只对确实需要重启的变更提示。
NR 不会因为切换 FG 而自动关闭。更改 NR 预设、执行分辨率或内存模型从下次启动生效。

HUD 分别记录真实、生成和应用 Present 速率。Present 数量可能超过屏幕刷新率，
不能当作实际显示帧数，也不能当作输入延迟。内存模型默认 New（`auto` 也选择 New）；Old 可对照，
性能与显存依场景而变，New 不保证更快。

## 操作

| 按键 | 功能 |
|---|---|
| F1 | 释放鼠标，点击游戏重新捕获 |
| F6 | 开关离线自由相机，无需 BBSC；右键观察，WASD 移动，E/Q 升降 |
| F8 | 首次启用 NR，之后切换 NR 效果 |
| Delete / Insert / L3+R3 | 打开设置；以自己的手柄绑定为准 |

原生鼠标、复合键编辑、手柄、Mods、DLC 挂载和联机页面保留。实际游戏语言由自有资产决定。
普通菜单提供画面和操作设置；完整调节、诊断与调试选项保留在默认收起的高级设置中；需要性能诊断时显式开启所选项。
仅展开高级设置不会启用 Validation、Profiling 或捕获；`--developer` 仍可用于开发。
正常游玩不启用 Validation、逐帧捕获、性能 Profiling 或 NR 图像抽样。

## 存档、设置和回退

启动时备份存档并使用独立副本；正常退出后，确认 GPU 资源释放，再同步进度。
异常或外部存档冲突时保留副本，不覆盖原进度。备份在所选存档目录的 `backups/`。

游戏内改过的图形设置在正常退出后保存，保留原按键、鼠标及其他未改设置。
如启动后外部程序又改了设置文件，本轮不会覆盖它。FG 选择有独立的偏好文件。
最近两轮成功会话保留额外存档副本，更早的重复副本可清理；失败会话与资源退休记录保留。

正式版本在 `runtime/releases/`，`runtime/current` 为当前版本，`runtime/previous` 保留上版。
回退只切换运行版本，不恢复或覆盖玩家存档与设置。不要删除正在运行的版本或强行放行资源保护。

若异常退出被安全保护阻止重开，请保留提示和日志；普通捕获错误本身不代表必须重启系统。
联机登录由玩家操作，服务器和多人内容仍需玩家实际验收。
