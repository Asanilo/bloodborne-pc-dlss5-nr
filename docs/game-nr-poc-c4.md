## Native changes

- `c4_nr_process.{h,cpp}`: private posix_spawn 64-bit Wine child, exact descendant PE/starttime identity, protocol4/execution-mode config, frame-count/case validation and continued actual waitpid; no helper in srOnly.
- `c4_game_bridge.{h,cpp}`: real game device/scheduler, persistent four dedicated DMA-BUF resources, same baseline/imported/FD-consume/retirement handshake and bounded deadlines. Hot uses actual API result/GPU completion/exact tuple only plus the independent conversion guard. Diagnostic4 keeps full C3 validators/readbacks/FNV/alpha/actual-half checks. Dynamic first/SR-reset/source-gap NR history rules remain.
- `c4_game_bridge.comp`: input SR/depth/MV same-texel conversion unchanged. Mandatory output RGBA32F→local RGBA16F conversion checks all four components for NaN/Inf/abs>65504; bad texels OR a 4B flag and are not stored/clamped. Any flag rejects the entire returned frame and keeps immutable original SR. Clear via FillBuffer; transfer→compute dependency and transfer|compute write→host read visibility cover the normal zero path and the error path. Read only after the existing output Flush and bounded completion. This conservative range guard does not certify actual half/alpha/poison/transport-signature correctness for uninspected hot pixels.
- Hot allocates neither the 82.944MB native CPU pixel readback nor C3 GPU full-scan pipelines/buffers. Diagnostic still creates them. Hot return acquires **Output only**, never reads externally owned Color; diagnostic acquires Color+Output for real source/alpha/signature validation. Both release before fenced consumed. Prior local-return merge last use completes before reuse; final destruction is deferred to the actual merge tick. Timeout/peer exit/failed guard quarantines and aborts; no normal FD-retirement claim on abnormal cleanup.
- Shared `vk_temporal_upscaler` and `vk_presenter`: default-off C4 HDR Run branch; one pending ledger, exact source+1 guest prepare guard, unique non-reused Present. Hot has no automatic Present dumps. Root may capture outside scored windows; diagnostic has the old actual completed Present dump. Actual routing and original scene alpha/SR fallback remain.
