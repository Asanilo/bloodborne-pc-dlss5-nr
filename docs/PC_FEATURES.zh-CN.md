# 玩家设置、键鼠与存档

本页适用于当前 NRBridge Preview。入口为安装目录的 AppImage 或 `./launch.sh`，
使用完整的设置、Online 和日志页面。功能总览见 [中文 README](../README.zh-CN.md)。

## 输入和语言

默认原生鼠标直接控制相机。F1 释放鼠标，点击游戏重新捕获；菜单使用指针，关闭菜单后
恢复转镜。失焦或取消捕获时丢弃旧输入。兼容问题可在启动器关闭“原生鼠标视角”，
退回摇杆模拟。锁定目标、自由相机和更多手柄场景仍需进一步覆盖。

启动器保留按键编辑、复合键、冲突提示、重置和预设。设置保存在所选 INI 中，由日常
协调器复制到本轮会话，不再用固定诊断配置覆盖。实际按键和提示以自己的绑定为准。

启动器可选简体中文；游戏内 bbport 设置支持中文字体。上游保留21种游戏语言选择，
具体游戏文本仍取决于用户自己的游戏资产；界面语言不等于额外提供游戏语言包。

## NR 和画面设置

当前 NR 验证配置：DLSS Quality、1920×1080、16:9或自动、抖动和物体运动向量开启、
旧内存模型。NR 下“自动”使用已验证的旧模型。选择不兼容参数会提示原因，不会静默
改写设置。关闭 NR 后可以使用普通超分选项，但不代表每项都经过 NR 实机矩阵验证。

进入可操作场景后，在启动器确认“进入游戏场景后开启 NR”。F8 只切换显示旁路，
不会停止 Helper。Delete 打开 NR 控制，参数修改需要 Apply。Insert／L3+R3 是
bbport 浮层。NR 闪烁、有效历史偶发骤降和亮尾仍未修复。

FSR4.1.1 DLL 转换因使用独立 GPU 流程，在 Preview 中明确禁用；已准备的资源仍可选择。

## 存档与退出

在启动器选择自己的存档目录。开始前沿用原存档锁和备份机制，游戏使用独立副本；
正常退出并取得真实 GPU 末用和资源退休证明后，再备份并同步回原目录。
异常退出、源存档被外部修改或复制失败时保留本轮进度，不覆盖来源。

备份位于所选存档目录的 `backups/`，私人会话位于
`NRBRIDGE_HOME/runs/<session>/profile/user/savedata/`。不要把诊断 seed 当作正式进度，
也不要绕过启动器同时运行多个写同一目录的程序。

正常关闭游戏并等待同步后再关启动器。HOLD 表示资源状态未能安全确认，不能通过
强杀或删除记录当作恢复。日志按钮打开本轮或上轮会话目录，便于保留取证和私人副本。

## 联网与管理器

Online 页面保留 The Hunter’s Dream／Discord 和 Seamless Hunt，以及可选 BBSC。
由玩家亲自登录；默认不自动使用账号。真实谏言、血迹、幻影、网络退出及多人仍待验收。

Steam／Lutris 可复用安装目录的 `launch.sh --play`；NR 模式仍保留完整启动器和场景确认，
避免启动器提前退出。管理器导出功能保留，当前版本的两端实际启动回归尚未完整完成。

构建与依赖见 [开发说明](../tools/nr_dev/README.md)，有限验收见
[Preview 状态](NRBRIDGE_PREVIEW_STATUS.md)。
