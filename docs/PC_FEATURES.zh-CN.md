# 当前玩家功能与限制

完整启动器统一管理游戏、存档、画面、输入、Mods、联网与日志。
日常入口、快捷键与回退见[玩家指南](PLAYER_GUIDE.zh-CN.md)。

| 功能 | 当前支持 |
|---|---|
| NR | 独立启用；F8 控制效果；Preset A/B/默认；Legacy 画质策略默认 |
| SR | DLSS、FSR、DLAA 与既有超分；Quality/Balanced/Performance 等档位 |
| FG | 关闭、AMD FSR x2、NVIDIA DLSS 2X–6X；互斥，NR 独立 |
| 动态尺寸 | 1080p、1440p、16:10/超宽屏；按实际 Color/Depth/Motion/HUDless 创建资源 |
| NR-only | 关闭超分时保留 NR，可与 FG 联动 |
| 内存 | Old 默认；New 可选，非通用性能升级保证 |
| 输入 | 原生鼠标、F1、离线 F6、复合键绑定、手柄、冲突提示 |
| 设置 | 简体中文/英语/俄语游戏内菜单；完整 GTK 选项与语言选择 |
| 存档 | 备份、独立副本、正常退出后同步、恢复入口；不使用开发 seed 替换玩家进度 |
| 安装 | 独立 Release + LTO 本机运行目录，current/previous 回退 |

FG 开关与 GPU DLSS 倍率支持游戏内调整；更换算法运行时需要重新启动，菜单仅在需要时提示。
DLSS 内部的标准与兼容调度是同一个 FG 后端的选项；CPU 回退与资源路径只在开发设置中出现。
FSR 3.1.6 保留为另一可选 FSR 实现。Smooth Motion 因未完成正常退出验证而不可选择。

普通模式默认关闭 Vulkan Validation、性能 Profiling、NR 诊断图像抽样和调试显示。
保留真实 GPU 完成、FD 所有权、生成帧编号、资源退休和存档保护，不能通过删记录跳过。
持久 shader/pipeline 缓存使用玩家目录，避免每次启动都丢弃缓存。

## 已知限制

- FSR FG 快速转镜可能出现生成帧植被位置错误；DLSS FG 的已有玩家测试未再复现。
- NR 可有轻微拖影或局部外观变化；本机版本保持 Legacy，不默认启用新 Fade 策略。
- NR 执行分辨率与高倍率 MFG 增加显存和 GPU 工作；真实 FPS 可能下降。
- DLSS 3X–6X 仅对已识别并验证的运行时使用内存内适配，不修改磁盘 NVIDIA DLL。
- NR 需匹配的运动向量与抖动；不支持的输入或后端明确拒绝，不静默替换算法。
- FSR 4.1.1 DLL 转换是独立 GPU 工作流，普通启动器不执行转换，已准备资源仍可使用。
- 联网服务、DLC 和更多游戏区域保留原功能；本轮本机交付不宣称重新验收全部联机内容。
- 本机依赖面向当前 CachyOS；不宣称适配所有 Linux 发行版，也不公开发布本轮二进制。

## Old / New 性能结论

此前一组探索数据：Old 41.55 FPS，New 42.83 FPS；P95/P99 分别为
35.38/38.29 ms 与 37.66/48.62 ms，设备总显存约 3994 与 5367 MiB。
这组数据早于后续修复，场景和运行条件不足以形成当前版本的普遍结论。
目前只能确认 New 不一定更快且可能占用更多显存，默认继续 Old。
